# WORKFLOW.md

## Task 진행 순서

1. `docs/PLANS.md`에서 현재 진행할 task를 확인합니다.
2. task 문서(`Tasks/<이름>.md`)를 열어 목표와 완료 조건을 확인합니다.
3. 관련 코드와 참조 구조를 먼저 읽습니다.
4. 구현합니다.
5. `./gradlew test`로 검증합니다.
6. task 문서의 상태와 체크리스트를 갱신합니다.
7. `docs/PLANS.md`의 상태를 갱신합니다.

## 상태 값

| 상태 | 의미 |
|------|------|
| `todo` | 아직 시작 안 함 |
| `in-progress` | 현재 작업 중 |
| `blocked` | 외부 의존 또는 사람 확인 필요 |
| `done` | 완료 조건 충족 |

## 규칙

- 한 번에 하나의 task만 `in-progress`로 둡니다.
- 사람 확인이 필요한 단계에서 다음 task로 넘어가지 않습니다.
- task 범위를 벗어나는 작업이 필요하면 새 task로 분리하고 사용자 승인을 받습니다.
